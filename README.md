# PI-ZSSR: Physics-Informed Zero-Shot Super-Resolution for Airborne Gravity Downward Continuation

Code, synthetic inputs and result tables for

> Shih, H.-C. *Deep Image Prior for Geophysics: A Physics-Informed Zero-Shot Super-Resolution Framework for Airborne Gravity Downward Continuation.* Submitted to the Journal of Geodesy (under review).

PI-ZSSR trains an untrained U-Net (Deep Image Prior) on a single observation grid: the network proposes a field at the target altitude, the field is upward-continued with the exact planar operator \(e^{-hk}\), and only candidates whose upward continuation matches the observation are accepted. Early stopping follows the discrepancy principle. A dual-constraint variant predicts an unobserved 0 m field from two survey altitudes.

## Repository layout

```
.
├── *.py                 all scripts (flat; run from this directory)
├── data/
│   ├── ggm/             EGM2008 / XGM2019e grids from GrafLab (synthetic inputs, RCR reference)
│   ├── masks/           LSC coverage masks (1 = observed pixel, nan = unobserved)
│   └── lsc/             fitted Tscherning–Rapp parameters (A, B, R_B) of the two surveys
├── results/
│   ├── ch3/             Section 3 (synthetic): tables, metrics, learning curves, summary maps
│   └── ch4/             Section 4 (Taiwan airborne): metrics, curves, figures
├── figures/             manuscript Figures 1–20
├── requirements.txt
└── CITATION.cff
```

Each `results/ch*/<section>/README.md` lists the inputs, scripts, exact command lines and the paper items (table / figure) that the folder supports.

## What is and is not included

| Included | Not included (see Data availability) |
|---|---|
| All Python code | Taiwan airborne gravity observations (`*.xyg`, 5156 m and 1620 m flight lines) |
| EGM2008 residual grids (n = 1081–2160 at 0 / 1500 / 5000 m) used in Section 3 | LSC residual grids on the 1′ Taiwan grid (`*_pred_grid_0.1.xyz`) |
| EGM2008 n ≤ 2000 / n ≤ 2160 and XGM2019e n ≤ 5540 grids used in Section 4 | LOO predictions at observation points |
| LSC coverage masks Ω_1620 and Ω_5156 (NaN pattern only, no values) | Filled priors, PI-ZSSR fields and restored full-*g* grids over Taiwan (derived from the above) |
| Fitted T–R parameters (A, B, R_B) | Per-run `*_fields.npz` / `*.xyz` of Section 3 (regenerated by the commands below) |
| Metrics (`*_metrics.json`), learning curves (`*_curve.csv`), tables, figures | |

The Section 3 (synthetic) experiments are fully reproducible from this repository. The Section 4 experiments need the airborne observations or the LSC grids derived from them; the corresponding commands are documented in `results/ch4/*/README.md` and run unchanged once those files are placed in the project directory.

## Environment

Python 3.10; PyTorch 2.9 (CUDA 12.6), NumPy 2.0, SciPy 1.14, pandas 2.2, Matplotlib 3.9 (`requirements.txt`). A CPU works for the 301² grids (minutes per run); the 1201² grids of Section 3.3.4 were run on an NVIDIA GPU. GMT (`gmt`) is optional and only used to draw coastlines.

```
git clone https://github.com/flex0902/PI-ZSSR.git
cd PI-ZSSR
pip install -r requirements.txt
```

## Reproducing Section 3 (synthetic)

All commands are run from the repository root. The scripts write to the directory given by `--dir` / `--prefix`.

**3.3.1 Stopping rule (Table 1, Figure 4)**
```
python run_e2.py --dir e2 --noises 0,1 --types white,corr --file_high data/ggm/TW_EGM_grid_g_res_h5000.xyz --file_low data/ggm/TW_EGM_grid_g_res_h1500.xyz
python plot_e1_curves.py --dir e2 --pattern white1_s* --out e2/E1_white1_curves
python plot_e1_curves.py --dir e2 --pattern corr1_s*  --out e2/E1_corr1_curves
# spatial hold-out variant discussed in the text
python blind_pisr_v2.py --file_high data/ggm/TW_EGM_grid_g_res_h5000.xyz --file_low data/ggm/TW_EGM_grid_g_res_h1500.xyz --noise 1 --holdout_frac 0.2 --holdout_block 15 --no_stop --seed 0 --prefix e1/white1_s0
```

**3.3.2 Noise robustness (Table 2, Figures 5–6)**
```
python run_e2.py --dir e2  --file_high data/ggm/TW_EGM_grid_g_res_h5000.xyz --file_low data/ggm/TW_EGM_grid_g_res_h1500.xyz
python run_e2.py --dir e2b --noises 2,3 --eval_every 1 --file_high data/ggm/TW_EGM_grid_g_res_h5000.xyz --file_low data/ggm/TW_EGM_grid_g_res_h1500.xyz
python summarize_e2.py --dirs e2 e2b --dir e2
```

**3.3.3 Sensitivity to the noise estimate τ (Table 3, Figure 7)** — post-hoc scan of the recorded curves, no training
```
python scan_tau.py --dirs e2 e2b --out e2/tau_scan
```

**3.3.4 Grid-size consistency (Table 4, Figure 8)**
```
python run_e4.py --dir e4 --file_high data/ggm/TW_EGM_grid_g_res_h5000.xyz --file_low data/ggm/TW_EGM_grid_g_res_h1500.xyz
python summarize_e4.py --dir e4
```
PSD-matched and decreasing-noise series are single `blind_pisr_v2.py` calls with `--size {601,901,1201}` and `--noise {2,3,4,0.5,0.3333}` (tags in `results/ch3/3.3.4_grid_size/`).

**3.4 Dual physics constraint (Table 5, Figure 10)** — coverage from the Taiwan LSC masks, values synthetic
```
python run_e3.py --dir e3_r01 --file_0 data/ggm/TW_EGM_grid_g_res_h0.xyz --file_1500 data/ggm/TW_EGM_grid_g_res_h1500.xyz --file_5000 data/ggm/TW_EGM_grid_g_res_h5000.xyz --mask_low data/masks/mask_lsc_1620m_r0.1.xyz --mask_high data/masks/mask_lsc_5156m_r0.1.xyz
python summarize_e3.py --dir e3_r01
```
The masks reproduce the pixel counts of the paper (R1 = 31941, R2 = 10446, R3 = 25734 inside the 20-px margin).

## Section 4 (Taiwan airborne)

Pipeline and command lines: `results/ch4/4.2_lsc` (RCR, T–R fit, LOO, gridding), `4.3_5156to1620` (labelled 5156 → 1620 m test and σ sensitivity), `4.4_0m_dual` (unobserved 0 m, configurations A and C), `4.5_xgm_egm` (residual spectra of the 0 m product against XGM2019e / EGM2008; §4.4.1). The GGM grids and T–R parameters they use are in `data/`; the airborne observations and the LSC grids are not distributed here.

## Data availability

The Taiwan airborne gravity observations were provided by the Ministry of the Interior, Taiwan, and are not redistributed. The LSC residual grids, PI-ZSSR predictions and other datasets derived from them are available from the corresponding author upon reasonable request. EGM2008 and XGM2019e coefficients are publicly available from ICGEM (http://icgem.gfz-potsdam.de); the grids in `data/ggm/` were synthesised with GrafLab (Bucha and Janák, 2013) on the 21–26°N, 119–124°E, 1′ window.
